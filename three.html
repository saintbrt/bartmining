Compare Files

compareFiles

Audits the physical structure, column setups, and shared keys across multiple uploaded tables before processing. This ensures datasets match up cleanly, avoiding query failures from missing columns or mismatched text formatting.

Files Selected For Relational Audit

File A: Collar_v1.csv (5 columns, 120 rows)

Headers: [hole_id, easting, northing, elevation, total_depth]

File B: Assay_v1.csv (4 columns, 2450 rows)

Headers: [HoleID, from_depth, to_depth, au_ppm]

Processing Logic
  • Reads the underlying headers and row data layouts from both designated spreadsheets.
  • Calculates structural overlap by comparing common alphanumeric keys across target columns.
  • Flags key mismatches, highlighting casing variations (like hole_id vs. HoleID).
  • Generates compatibility ratings to verify if the files can join cleanly without data loss.

Reconcile Columns

reconcileColumns

Maps different historical column headers containing the same underlying data down to a single canonical system name. This aligns naming variations across historical files without altering raw text data.

Raw Incoming Variations (Varying Header Fields)

Spreadsheet Upload Field Samples:

  • File 1: [hole, east, north, elev_m]
  • File 2: [HoleID, Easting, Northing, RL]
  • File 3: [HOLE_ID, X_UTM, Y_UTM, Z_ELEV]
Processing Logic
  • Runs string similarity analysis against predefined schema aliases.
  • Matches string variants (like RL, elev_m, Z_ELEV) to the system standard (elevation).
  • Constructs a structural column mapping matrix without renaming raw file data.
  • Saves the translation map template to streamline future file imports.

Diff Files (Version Comparison)

diffFiles

Compares baseline datasets with newer versions to track precise data changes. Running full outer joins on natural keys cleanly lists which rows were added, removed, or modified between file versions.

File Multi-Version Input (Base Layer vs. Updated Sheet)

Base Master Version Ledger (v1):

[KS26_901: 150m, KS26_902: 200m, KS26_903: 85m]

Incoming Candidate Version Sheet (v2):

[KS26_901: 150m, KS26_902: 225m, KS26_904: 110m]
Processing Logic
  • Performs a full outer join matching on natural keys across target tables.
  • Flags records unique to the new file as ADDED entries.
  • Flags records omitted from the new file as REMOVED entries.
  • Compares data attributes across matching keys, tagging changed data points as MODIFIED.

From >= To Errors

checkFromToErrors

Verifies downhole physical mechanics within interval tables (such as assays or lithology log files). Downhole depth segments must read chronologically downward, meaning an interval's start point must strictly precede its end point.

Raw Input Dataset (Assay Table)
hole_idfrom_depthto_depthau_ppm

KS26_0014.002.001.45
KS26_0014.006.002.11
KS26_0018.008.000.05
KS26_0018.0010.000.98
Processing Logic
  • Inspects records where both interval parameters (from_depth and to_depth) are numeric.
  • Flags records where from_depth > to_depth, indicating an impossible physical inversion.
  • Flags records where from_depth = to_depth, representing an unmeasurable zero-thickness slice.
  • Extracts the precise Hole ID and inverted measurements to isolate them for physical depth reassignment.

Interval Overlaps

findIntervalOverlaps

Identifies overlapping downhole depth designations within the same core trajectory. Physical drill core samples cannot exist in two places simultaneously; overlapping intervals point to structural logging or entry errors.

Raw Input Dataset (Assay Sequence)
hole_idfrom_depthto_depthsample_id

Processing Logic
  • Groups downhole records systematically by their distinct parent hole_id.
  • Compares each interval (A) against every other interval (B) logged inside that distinct borehole.
  • Evaluates overlapping states via intersection math: from_A < to_B AND to_A > from_B.
  • Ignores natural adjoining edges where to_A = from_B, isolating actual internal intersections.

Interval Gaps

findIntervalGaps

Scans continuous downhole series layouts to uncover undocumented depth gaps. Gaps are common in selective sampling but must be identified to ensure unassayed core segments aren't accidentally treated as continuous or zero-grade zones.

Processing Logic
  • Orders logging intervals sequentially by from_depth nested under parent boreholes.
  • Iterates forward, comparing the to_depth of row N against the subsequent from_depth of row N+1.
  • Detects structural gaps whenever a subsequent from_depth value exceeds the preceding to_depth.
  • Excludes deliberate non-sampled zones if specified by project parameters, flagging unexpected breaks.

Negative Grade Values

findNegativeGrades

Flags structural numeric values less than zero inside geochemical analytical fields. Laboratory database exports often use negative values to denote special criteria (like lower limits of detection), which distort resource estimations if processed as real values.

Processing Logic
  • Scans all designated numeric geological metrics (such as au_ppm or cu_pct).

Ensures every row in the master Collar table contains all mandatory spatial parameters required for 3D coordinate processing. A collar record requires a Hole ID, X (Easting), Y (Northing), Z (Elevation), and Total Depth to be usable.

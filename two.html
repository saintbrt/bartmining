Standardise Hole IDs

standardiseHoleIDs

Resolves manual data entry differences across datasets by fixing casing, whitespace, and delimiter variations. Standardizing these formats establishes a clean canonical layout, allowing relational tables to link cleanly using identical keys.

Processing Logic
  • Applies string trimming logic to strip all leading and trailing whitespace characters.

  • Detects missing delimiters using prefix-matching patterns and inserts the standard underscore separator safely.

Remove Undrilled Holes

removeUndrilled

Purges planned or uncompleted drilling setups from the working database once an active field campaign concludes. Removing these entries prevents un-drilled locations from skewing downhole database joins or creating blank gaps in 3D modeling packages.

Resolve Unit Conflicts (ppm vs ppb)

resolveUnitConflicts

Detects and fixes mixed measurement units within geochemical grade datasets (such as blending parts per million with parts per billion). Standardizing these variations prevents serious 1,000× mathematical scaling distortions that can compromise resource estimations.

Build Collar Output

buildCollarOutput

GoldPass’s core deliverable—aggregates the maximum gold grade (MAX(au_ppm)) and its corresponding peak interval for every single hole, mapping it back to coordinates for GIS programs.

Processing Logic

Find Best Intercept

findBestIntercept

Computes a continuous, length-weighted average mineralized interval above a specified cutoff grade, accommodating localized internal waste blocks without breaking data continuity constraints.

Continuous Downhole Sample Run (Cutoff: 0.50 ppm)

Processing Logic
  • Applies a length-weighting equation: SUM(Interval Length * Grade) / SUM(Interval Length).
  • Triggers calculation windows when values cross user-defined cutoff boundaries.
  • Permits low-grade internal waste zones if nearby higher-grade intervals maintain the overall average above cutoff rules.
  • Saves and outputs total composite width, length-weighted grade, and upper/lower depth tags.

Find Correlation (Litho vs Grade)

findCorrelation

Uses true depth-interval overlap logic to correlate assay grades against rock types or alteration styles, showing which host environments hold the highest gold concentrations.

Overlapping Interval Mappings

Lithology Table Logs:

[0.0 - 12.5m: Saprolite] • [12.5 - 50.0m: Quartz Porphyry]

Assay Table Logs:

[12.0 - 13.0m: 14.65 ppm] → 0.5m in Saprolite, 0.5m in Quartz Porphyry

Processing Logic
  • Calculates intersection boundaries where assay intervals overlap with lithological entries.
  • Apportion composite gold grades down to sub-units based on exact overlap distances.
  • Groups values by rock code to aggregate structural grade properties across the project area.
  • Calculates descriptive statistics (mean, median, peak grade) for each distinct geological host unit.
